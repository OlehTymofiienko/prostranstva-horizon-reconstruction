Исходное поле − аппроксимация

Единая шкала трёх карт, постоянная по времени для выбранного поля. Оранжевые границы обозначают прежнюю область B4. Квадрат невязки — численная норма, не физическая энергия.

В первом кадре Re Ψ₂ два узла при θ=90°, φ=40° и 220° дают 83,14% квадрата нормы остатка для ℓ≤8. Они сохранены в отображении и в полном численном результате. Их физическая природа по этому тесту не установлена.
