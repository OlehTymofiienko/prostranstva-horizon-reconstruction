Шаг завершён 2026-09-16. Следующий шаг: HF4-A2, динамический атлас скалярных полей общего горизонта. Пользователю сейчас не требуется ничего запускать.

Главный текст: `results/BH_HF4_A1_report.md`. Точка продолжения: `results/BH_HF4_resume_state_A1.json`.

## Содержимое

- `BH_HF4_A1.py` — программа расчёта и построения рисунков. Не запускает эволюцию и не меняет входы.
- `input/Moments_500M_L30.h5` — полный исходный HDF5 Yitian; 5001 время, 81 комплексный коэффициент каждого типа.
- `input/author_notebooks/` — четыре исходных авторских блокнота, включены без исполнения.
- `input/BH_HF3_R7A_output.zip` — возвращённый пользователем архив QC0; здесь используется только для инвентаризации геометрического вывода.
- `provenance/BH_HF3_resume_state_R7B.json` — предыдущая подтверждённая точка.
- `results/BH_HF4_A1_summary.json` — новые численные итоги, условия и ограничения.
- `results/BH_HF4_A1_scalar_maps.png` — скалярные поля, четыре времени, постоянные цветовые шкалы.
- `results/BH_HF4_A1_reconstruction_checks.png` — чувствительность к отсечению, осесимметричный контроль и математический пример неоднозначности.
- `results/BH_HF4_A1_scalar_snapshots.npz` — times_M [0,5,20,80]; latitude — широта; longitude — азимут; K и B имеют форму (4,91,181), порядок (время, широта, азимут).
- `results/BH_HF4_A1_norms_and_late_profile.npz` — нормы исходных полей на всех 5001 временах; ключи `*_shell_L2` имеют форму (5001,9). Нормы `*_L2` заданы относительно dΩ, а доли — числа от 0 до 1. `late_*` содержит профиль осесимметричного контроля в единицах радиуса по площади. `late_*alternative*` — искусственный математический пример, не данные симуляции.
- `manifest.json` — контрольные суммы файлов пакета, кроме самого манифеста.

## Соглашения

Комплексные коэффициенты HDF5 сопрягаются по авторским примерам. k=ℓ(ℓ+1)+m. Использованы ортонормированные Yℓm с exp(+imφ), θ — полярный угол. Исходные поздние постоянные моменты не вычитаются, дополнительного поворота exp(−imΩt) нет.

K = 2 Σ Iℓm Yℓm = R² K_G, B = Σ Lℓm Yℓm = −R² curl(ω)/2; суммы ограничены ℓ≤8. Эти поля не являются радиусом поверхности или её скоростью. Ранняя стационарная идентификация с Ψ₂ не применяется.

Различия при отсечениях не оценивают неизвестные ℓ>8. Поздняя модель m=0 и её евклидово вложение условны; пространственный срез SpEC из них не восстановлен. QC0 и Yitian не объединены в одну симуляцию.

## Воспроизведение при необходимости

Python ≥3.10, NumPy, SciPy ≥1.15, h5py, matplotlib. Проверенные версии записаны в `requirements.txt`.

```bash
python BH_HF4_A1.py --moments input/Moments_500M_L30.h5 --qc0-archive input/BH_HF3_R7A_output.zip --out reproduced_results
```

Программа заново создаёт численные итоги, NPZ и рисунки. Поясняющий отчёт и запись исследовательского состояния включены как отдельные подготовленные документы. Архив не содержит исполняемых файлов Einstein Toolkit, пользовательских checkpoint-файлов или полного пространства-времени.
