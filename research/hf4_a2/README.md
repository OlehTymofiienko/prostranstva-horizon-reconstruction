# HF4-A2 — динамический атлас общего горизонта

Этап завершён 16 сентября 2026. Продолжение HF4-A1 без новой эволюции.

## Посмотреть результат

Откройте `results/BH_HF4_A2_atlas.html` в браузере. Файл самодостаточен и не обращается к интернету. Можно выбрать время, полное поле/возмущение, поворот углов и линейную/сжатую шкалу. Три карты показывают ℓ≤4, 6, 8 одновременно.

`results/BH_HF4_A2_dynamics.mp4` — готовое видео 301 кадра. Подробности и ограничения: `results/BH_HF4_A2_report.md`. Контрольная точка: `results/BH_HF4_resume_state_A2.json`.

## Воспроизведение

Необязательная команда из папки распакованного архива:

```bash
python BH_HF4_A2.py --moments input/Moments_500M_L30.h5 --parent-state provenance/BH_HF4_resume_state_A1.json --out reproduced_results --video
```

Python ≥3.10; NumPy, SciPy≥1.15, h5py, matplotlib. Проверенные версии перечислены в `requirements.txt`. Для видео используется `ffmpeg` из PATH. Без `--video` видео не строится. Программа не запускает Einstein Toolkit и не меняет входы.

HTML формируется из `atlas_template.html`, который должен находиться рядом с программой. Отчёт и контрольная точка включены как отдельные подготовленные документы.

## Числовое представление

Полные безразмерные коэффициенты C равны 2I для K и L для B. Из комплексных HDF5-массивов сначала берётся сопряжение по авторскому соглашению. Исходный индекс k=ℓ(ℓ+1)+m.

В массиве `packed_coefficients` размерности (4,301,81) порядок полей — K, B, δK, δB. Блок степени ℓ начинается с индекса ℓ². Первый элемент — Re(Cℓ0); далее для каждого положительного m идут 2Re(Cℓm) и −2Im(Cℓm). Соответствующие базисные функции — Yℓ0, Re(Yℓm), Im(Yℓm). Это сохраняет вклад пары ±m при условии вещественности.

Возмущения получены в двойной точности вычитанием среднего за 400–500 M до передачи в файл атласа. Они не вычисляются вычитанием округлённых пикселей или коэффициентов одинарной точности.

При повороте exp(−imΩt), Ω=0.20878380853617037, преобразуются вместе сигнал и исходный эталон. Нормы и разности отсечений от поворота не меняются.

`BH_HF4_A2_analysis.npz`: время в M, нормы L² относительно dΩ, разности в долях (не процентах), средние комплексные коэффициенты. `BH_HF4_A2_atlas_coefficients.npz`: 301 время, упакованные коэффициенты, широта от +90° до −90° и азимут от −180° до +180°.

## Проверки

Контроли обработки — в `BH_HF4_A2_summary.json`. Числовой расчёт атласа дополнительно проверен независимым гармоническим вычислением и обработчиками управления; результат — `BH_HF4_A2_viewer_validation.json`. `validate_atlas.js` документирует эту проверку в Node с `@napi-rs/canvas`. Полная проверка компоновки страницы в браузере не выполнена. Кадры видео и проверочные рисунки визуально проверены; видео полностью декодируется.

`manifest.json` содержит контрольные суммы файлов пакета. Исходные коэффициенты включены, но полная сетка поверхности и пространственная метрика в пакете отсутствуют. QC0 сохранён как предшествующий результат; его массивы не используются для построения этих карт SpEC.
