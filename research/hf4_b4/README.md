# HF4-B4

Завершённый результат: все 55 ранних общих поверхностей QC0 доступны,
восстановленная физическая площадь сверена с QLM того же запуска.
Обработаны только 43 добавленных кадра; прежние 12 кадров B3 переиспользованы.

Для просмотра откройте `results/BH_HF4_B4_fields_3D.html` в браузере.
Доступны смена кадров, поля Re Ψ₂, Im Ψ₂ и модуль σ, выделенные области,
внутренние горизонты и облёт камеры. Файл автономный; сеть не требуется.

Для продолжения читать `results/BH_HF4_resume_state_B4.json`, отчёт B4 и
`results/BH_HF4_B5_protocol.json`. Новый этап B5 ещё не вычислялся.
Программу B4 для продолжения запускать повторно не нужно.

## Состав

- `BH_HF4_B4.py`: проверка ранней площади и обработка добавленных кадров.
- `build_B4_view.py`, `viewer_template.html`: просмотр и график из готовых данных.
- `check_B4_view.cjs`: проверки данных и логики управления без WebGL-рендера.
- `results/`: численные массивы, таблицы, отчёт, рисунок и контрольная точка.
- `provenance/`: диагностические ряды и параметры именно раннего запуска.
- `BH_HF4_B4_manifest.json`: размеры и SHA-256 файлов результата.
- Соседние `hf4_b3/` и `hf4_b2/`: необходимые сохранённые зависимости.

## Только для явного воспроизведения

Нужны Python, NumPy, Matplotlib. Для проверки контроллера нужен Node.js.
Исходный `BH_HF4_B4_collection(1).zip` следует извлечь в `hf4_b4/input`,
сохранив каталоги `surfaces`, `shapes`, `diagnostics`, `parameters`.
Контрольная сумма архива указана в отчёте и состоянии продолжения.

```bash
python hf4_b4/BH_HF4_B4.py
python hf4_b4/build_B4_view.py
node hf4_b4/check_B4_view.cjs
```

Эти команды воспроизводят B4, а не продолжают исследование. Результаты уже
сохранены. Исходный архив объёмом около 96 МБ в пакет результатов не дублируется.

Разделы отчёта об ограничениях обязательны для научной интерпретации:
нет второго разрешения симуляции, произвольной независимости от тетрады
или доказанного тождества выделенных областей структуре HF1.
