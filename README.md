# Пространства — реконструкция горизонтов чёрных дыр

**Русский** · [English](README.en.md)

Сайт доступен на русском и английском. В верхней панели каждой страницы можно выбрать светлую, тёмную, тёплую тему или тему системы. Выбор темы сохраняется в браузере; научные цветовые шкалы не изменяются.
Исследовательский выпуск **1.0**, 22 сентября 2026 года.

Проект объединяет реконструкции поверхностей, карты полей, видео,
временные ряды, программы анализа и проверки результатов HF1–HF4-B5.
Три численные конфигурации рассматриваются раздельно:

| Ветка | Конфигурация | Что восстановлено |
|---|---|---|
| HF1/HF1R | SXS:BBH:0305, Lev6, общий горизонт C | Координатные поверхности и выделенные по градиенту области R*, E*, B* |
| HF3 / HF4-B | Einstein Toolkit QC0 | Кольцевание до 105M; ранние поверхности, поля и физическая мера площади; угловая проверка B5 |
| Yitian / HF4-A | SXS:BBH:0389, SpEC | Скалярные угловые карты по массовым и спиновым мультиполям до ℓ=8 |

**Завершённость:** реконструкция и описательная проверка доступных данных.
Проект не устанавливает новую физику, не восстанавливает глобальный горизонт
событий и не содержит непрерывной проверенной геометрии QC0 от 0 до 105M.
Полный научный вывод и открытые вопросы — в [PROJECT_REPORT.md](docs/PROJECT_REPORT.md).

## Посмотреть

**Сайт проекта:** https://olehtymofiienko.github.io/prostranstva-horizon-reconstruction/

Откройте `dist/index.html` в современном браузере. Сайт и просмотры используют
локальные файлы; интернет для чтения не нужен. HTML-просмотры HF1 и QC0
нуждаются в поддержке WebGL. Если просмотр недоступен, видео и изображения
остаются доступны.

- `dist/viewers/hf1.html` — исходная область HF1 на 3D-поверхности.
- `dist/viewers/qc0.html` — отдельные и общий горизонты QC0, поля и маски.
- `dist/viewers/yitian.html` — атлас скалярных полей по мультиполям.
- `dist/viewers/b5.html` — поле, угловая аппроксимация и остаток B5.
- `dist/materials.html` — каталог отчётов, таблиц и программ.

Не перемещайте один HTML-файл отдельно от соседних `assets`, `viewers`,
`reports` и `downloads`: это единый сайт. Видео можно открывать отдельно.

## Новое в B5

На 55 кадрах QC0 от 18,625M до 22M выполнены 660 взвешенных подгонок полей
в координатных сферических гармониках до L=2,4,6,8. До L=8 описано:

| Поле | Доля угловой вариации по всем временам |
|---|---:|
| Re Ψ₂ | 96,388–99,977% |
| Im Ψ₂ | 99,074–99,962% |
| Модуль σ | 99,815–99,936% |

В первом кадре Re Ψ₂ два узла дают 83,14% квадрата нормы остатка.
Они сохранены; их физическая природа этим анализом не установлена.
R² — качество описания на тех же узлах, не вероятность и не точность
симуляции. Подробности — в [отчёте B5](research/hf4_b5/results/BH_HF4_B5_report.md).

## Структура

- `dist/` — готовый статический сайт со всеми четырьмя просмотрами и двумя видео.
- `research/` — программы, сохранённые численные результаты и история этапов.
- `docs/` — итог, происхождение данных, воспроизводимость, перечень файлов.
- `scripts/` — сборка сайта из готовых результатов и проверка публикационного пакета.
- `CHECKPOINT.json` — точное состояние для продолжения без пересчёта.
- `SHA256SUMS.json` — контрольные суммы выпуска.

## Воспроизводимость

Обычное продолжение не требует повторного запуска анализа. Для независимого
воспроизведения B5 включены все его входные данные:

```bash
cd research/hf4_b5
python -m pip install -r requirements.txt
python BH_HF4_B5.py --input input/BH_HF4_B4_fields_geometry_masks.npz --protocol input/BH_HF4_B5_protocol.json --geometry input/BH_HF4_B4_geometry.csv
python finish_B5.py
```

Старшие исходные наборы поверхностей, исходный файл мультиполей из переписки
и полный Einstein Toolkit в этот выпуск не входят. Сохранены результаты и
программы; точные внешние зависимости указаны в `docs/REPRODUCIBILITY.md`.
Исходные сообщения и переписка не публикуются. Исторические отчёты сохранены;
при расхождении формулировок актуален итоговый отчёт и финальный R7B/B5.
